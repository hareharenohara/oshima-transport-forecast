# カード別の更新時刻表示（ローカル変更）

- 日付カードだけに最終更新と次回更新予定を表示します。便別・集約評価の行や詳細画面には更新時刻を表示しません。
- 最終更新は公開された予測の時刻です。日別カードは表示対象の予測のうち最新の公開時刻です。
- 次回は日数別の処理開始予定です。日付が変わる場合は、その時点の日数に合った更新スケジュールを使います。
- 当日は公式状況の更新日時と出港1時間前の締め切りを反映します。朝の公式発表前や翌日から当日に変わる場合は対象条件がまだ確定していないため、条件付き予定を表示します。
- 現在の条件で更新対象がない便には「予定なし（現在の対象条件）」を表示します。公式状況が変わると予定を再計算します。
- 画面上部の全体更新時刻表示は削除し、再読み込みボタンはヘッダーに移しました。
- ２日後以降の集約評価も便別と同じ行形式（午前・午後・終日、船種、対象航路、評価）にそろえました。クリックすると共通の詳細画面を開き、評価・確信度・根拠・対象便を確認できます。
