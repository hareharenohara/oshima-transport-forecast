# 地点分離ML V2 実験仕様

## 目的

V1の「航路上の全地点・全時刻を平均／最大／最小に圧縮する」方式では、危険な地点の場所をモデルが識別できない。V2では元の地点別・時刻別データから特徴量を再構築し、重要地点の状態を独立した入力として保持する。

## 変更しないもの

- 目的変数: 当該便が気象・海象理由で欠航する確率
- 元データ: 同梱された運航実績、Open-Meteo ERA5／海洋履歴データ
- 単位: 風速 m/s、気圧 hPa、波高 m、周期 s、時間 JST
- 時系列分割: 学習 ～2025-09、校正 2025Q4、検証 2026-01～05、最終テスト 2026-06～09-17

## 比較した構成

### V2 point-full

11地点を完全に別列化した298特徴量。地点ごとの風、波、うねり、方向、変化量、基準超過時間を保持する。最終テストで過学習が見られ、V1を下回った。

### V2 hybrid

V1の航路全体特徴量を残し、以下を地点別に追加した192特徴量。

- 大島北・岡田側
- 大島西・元町側
- 相模灘中央
- 浦賀水道
- 便ごとの対岸港

各地点について最大風速、最大突風、最低気圧、最大波高、波周期、最大うねり、うねり周期、出航前値、3／6時間変化、基準超過時間を保持する。

## 初回結果

- V1ロジスティック: Test PR-AUC 0.6985、Brier 0.0529、Recall 92.3%
- V2 hybrid GBDT: Test PR-AUC 0.7222、Brier 0.0572、Recall 93.3%
- V1ロジスティック85%＋V2 hybrid GBDT15%: Test PR-AUC 0.7130、Brier 0.0524、Recall 92.3%

V2地点情報は順位性能に補助的な改善を示したが、単独で確率校正まで改善したとはいえない。95%信頼区間も重なるため、本番採用は未決定とする。

## 既知の制約

- 岡田と元町は海洋APIから同じ返却グリッドが得られており、海況は実質的に分離できない。天気地点の座標は別。
- 欠航802便は116日間に集中しており、有効な独立荒天事例が少ない。
- 履歴は実測・再解析であり、当時取得可能だった未来予報ではない。
- 本番化前に、2時間ごとの予報スナップショットと実績結果を蓄積して再評価する。

## 再現手順

1. `python scripts/build_v2_point_features.py`
2. `python scripts/train_model_v2_offline.py`

生成物は `artifacts/model_v2_offline/` に保存する。`models/` とWorkerは変更しない。
