# AI就航評価の段階表示

AIの最終判断は細かな確率を生成せず、次の2軸で返す。

- `evaluation_grade`: `A`（就航の可能性が高い）、`B`（就航寄り）、`C`（判断が分かれる）、`D`（欠航寄り）、`E`（欠航の可能性が高い）
- `confidence_level`: `5`（非常に高い）、`4`（高い）、`3`（中程度）、`2`（低い）、`1`（非常に低い）

確信度は評価自体の信頼度であり、就航評価とは別軸である。UIでは右へ行くほどポジティブになるよう、就航評価を `E D C B A`、確信度を `1 2 3 4 5` の順で表示し、現在位置を文字とマーカーで示す。

MLモデルの就航確率は、過去実績と気象予報から算出した統計的な参考値として保持する。AI評価と混同しない表示・API名を用いる。旧AIパーセント列は履歴互換のためデータベースに残すが、新しい予測では書き込まず、画面にもAI評価として表示しない。

AIが生成する説明文、要約、要因、確信度の根拠、港予測の根拠は自然な日本語とする。モデル名、単位、APIやデータ上の正式な識別子は原表記を保持できる。応答後の言語判定や再生成は行わず、生成指示によって統一する。
